# Idea Beacon — Android Releases

Official download repository for the Idea Beacon Android application.

## Download

The signed Android APK will be attached to the latest GitHub Release.

- **Latest release:** https://github.com/yashwanth0630-ui/IdeaBeacon-Android-Releases/releases/latest
- **Direct APK download (after the release asset is published):** https://github.com/yashwanth0630-ui/IdeaBeacon-Android-Releases/releases/latest/download/IdeaBeacon-Android.apk

If no release has been published yet, open the Releases page above and check back after the first version is uploaded.

## Install

1. Download `IdeaBeacon-Android.apk` to your Android device.
2. Open the downloaded APK.
3. If Android prompts you, allow your chosen file manager or browser to install unknown apps.
4. Follow Android's installation prompt.

Only install APKs published in this repository's official Releases section.

## Versioning

Releases use version tags such as `v1.0.0`. Each release should include a short changelog and the signed APK asset named exactly `IdeaBeacon-Android.apk`.

## Maintainer notes

- Upload the signed release APK as a **Release asset** rather than committing large APK files to the Git repository.
- Never commit signing keystores (`.jks`, `.keystore`) or passwords.
- Keep the original signing key backed up securely so future app updates can be signed with the same key.
